# Руководство пользователя WMS

Документ описывает повседневную работу в веб-интерфейсе и на ТСД. Предполагается, что у вас уже есть учётная запись и назначена роль.

---

## 1. Вход и навигация

### Вход в систему

1. Откройте адрес WMS в браузере.
2. Введите **логин** и **пароль**.
3. После входа откроется раздел **Обзор**.

Если видите страницу «Доступ запрещён» — у вашей роли нет права на этот раздел. Если «Модуль выключен» — администратор отключил соответствующий функционал в настройках склада.

### Левое меню

Порядок пунктов настраивает администратор. Типичная структура:

- **Обзор** — сводка по потокам
- **НСИ** — справочники склада
- *Пользовательские разделы* — если администратор их создал
- **Остатки** — отчёты по запасам
- **Операции** — журнал складских задач
- **Приёмка** / **Отгрузка** — если модули включены
- **Администрирование** — только для администраторов
- **ТСД** — открывается в **новой вкладке**

---

## 2. Обзор

**Путь:** главная страница после входа.

На обзоре видны блоки по доступным потокам:

| Блок | Метрики |
|------|---------|
| Приёмка | «Запланировано» (новые заказы), «В работе» (к исполнению) |
| Отгрузка | То же для исходящих документов |
| Внутренние операции | Задачи размещения, перемещения и т.п. |

Клик по метрике открывает список с уже применённым фильтром по статусу.

Внизу — таблица **последних движений**: когда, какая операция, товар, количество, маршрут (откуда → куда). По строке можно перейти к связанной задаче, если она есть.

---

## 3. Приёмка

**Путь:** Приёмка → список документов.

Модуль может быть отключён администратором — тогда раздел недоступен.

### Список документов

- Фильтры по **статусу**, **типу** документа, поиск по номеру, поставщику и другим реквизитам.
- Создание нового заказа — кнопка «Создать» (нужно право на редактирование приёмки).

### Карточка документа

- Реквизиты шапки: поставщик, даты, номера внешних документов, комментарий и др.
- **Плановые строки** — что ожидается к приёмке.
- **Фактические строки** — что принято на складе (часто заполняется через ТСД).
- **История статусов** — кто и когда менял статус.
- Смена статуса — через форму на карточке (при наличии права на редактирование).

### Типичный жизненный цикл

```
Новый → К исполнению → [приёмка на ТСД] → Принят → [размещение] → Размещён
```

- **Новый** — документ создан, работа ещё не начата.
- **К исполнению** — заказ передан на склад; на ТСД он появляется в списке приёмки.
- **Принят** — товар принят (по факту операций).
- **Размещён** — все товарные носители размещены в зоне хранения.

На любом этапе (кроме финальных) документ можно **отменить**.

### Справочники приёмки

| Раздел | Назначение |
|--------|------------|
| Рампы | Погрузочные места для машин |
| Транспорт | ТС, водители, перевозчики |

Используются в документах приёмки и отгрузки.

---

## 4. Отгрузка

**Путь:** Отгрузка → список документов.

Логика аналогична приёмке, но для исходящих заказов.

### Типичный жизненный цикл

```
Новый → К исполнению → [отбор на ТСД] → Проведён
```

- **К исполнению** — заказ готов к отбору на складе.
- **Проведён** — отгрузка завершена, остатки списаны.

В карточке: клиент, строки отбора, рампа, транспорт, история статусов.

---

## 5. Операции

**Путь:** Операции.

Единый журнал складских **задач**, не путать с «движениями» на обзоре (там — факт движения остатков).

| Тип операции | Назначение |
|--------------|------------|
| Отчёт о приёмке | Фиксация факта приёмки |
| Размещение | Перемещение ТН из зоны приёмки в ячейку хранения |
| Перемещение | Перенос между ячейками |
| Отбор | Подготовка товара к отгрузке |

Фильтры по статусу и типу. Быстрые пресеты: «Запланировано», «К исполнению», «Выполнено».

Статусы задач:

```
Новый → К исполнению → Выполнено (Проведён / Завершён)
```

---

## 6. Остатки

**Путь:** Остатки.

Отчёт по текущим запасам на складе.

### Фильтры

- Товар, зона, ячейка
- Партия, срок годности (если модуль «Партии» включён)
- Модель учёта, дополнительные реквизиты номенклатуры

### Группировка

| Режим | Что показывает |
|-------|----------------|
| Детально | Каждая строка: ячейка × товар (и партия при детализации) |
| По товару | Сводка по номенклатуре |
| По зоне | Сводка: зона × товар |
| По ячейке | Сводка: ячейка × товар |

Есть **быстрые пресеты** (например, партии с истекающим сроком).

### Экспорт

Отчёт можно выгрузить в **CSV** или **Excel** — кнопки на странице отчёта.

> Отдельного документа «инвентаризация» в системе нет. Сверка выполняется через детальный отчёт и экспорт; корректировки остатков — при наличии соответствующего права у роли.

## 7. НСИ — справочники

**Путь:** НСИ.

Хаб со **всеми справочниками** склада. На карточках — количество записей и переход в список.

### Системные справочники

| Справочник | Содержание |
|------------|------------|
| Номенклатура | Товары: SKU, название, единицы, упаковки |
| Контрагенты | Поставщики и клиенты |
| Зоны | Зоны склада (приёмка, хранение, отгрузка…) |
| Ячейки | Адресное хранение |
| Типы ТН | EUR-паллета и др. |
| ТН | Паллеты и товарные носители |
| Упаковки | ВГХ, коэффициенты пересчёта |
| Единицы | шт, кг, м³… |
| Модели учёта | Схемы учёта остатков |
| Штрихкоды | ШК товаров, ячеек, ТН, упаковок |
| Топология | План склада (если модуль включён) |
| Партии | Партии и сроки годности (если модуль включён) |

### Пользовательские справочники

Администратор может создать **свои** справочники с произвольными полями. Они отображаются на хабе НСИ или в пользовательском разделе меню — в зависимости от настройки.

### Работа со списком

- Поиск и фильтры (зависят от справочника).
- **Создать** — новая запись.
- Открытие карточки — просмотр и редактирование полей.
- Право только на просмотр — поля недоступны для изменения.

### Штрихкоды и печать этикеток

**Путь:** НСИ → Штрихкоды (или `/labels`).

- Справочник всех штрихкодов в системе.
- Выбор записей и **печать** этикеток (Code128 или QR).

### Топология

**Путь:** НСИ → Топология (если модуль включён).

- Визуальная **карта склада**: ячейки на плане.
- Перетаскивание блоков для сохранения расположения.
- Настройка размера холста.

---

## 8. Пользовательские разделы меню

**Путь:** `/m/…` — пункты, созданные администратором.

На странице раздела — карточки **пользовательских справочников и документов**, привязанных к этому разделу. Это может быть, например, «Претензии», «Акты брака» и т.п.

### Пользовательские документы

**Путь:** из раздела меню или НСИ → `/doc/…`

- Список документов, создание, редактирование карточки.
- Поля настраивает администратор (номер, дата, комментарий и свои реквизиты).
- **Без** строк табличной части, проведения и влияния на остатки — в отличие от приёмки и отгрузки.

## 9. ТСД — терминал сбора данных

**Путь:** пункт «ТСД» в меню (новая вкладка).

Интерфейс для работы **на складе** со сканером штрихкодов.

### Первичная настройка устройства

1. Администратор задаёт **API-ключ ТСД** в настройках склада.
2. На терминале: **ТСД → Устройство** — ввести ключ и имя устройства.
3. Войти под своим логином и паролем.

### Главное меню ТСД

| Операция | Когда доступна |
|----------|----------------|
| Приёмка | Модуль приёмки включён + право «ТСД: приёмка» |
| Размещение | Модуль приёмки или топологии + право «ТСД: размещение» |
| Отбор | Модуль отгрузки + право «ТСД: отбор» |
| Перемещение | Право «ТСД: перемещение» |
| Устройство | Всегда |

Если кнопка неактивна — нет права или выключен модуль.

### Приёмка на ТСД

1. Выбрать заказ на приёмку (статус «К исполнению»).
2. Отсканировать **ячейку приёмки**.
3. Отсканировать или создать **товарный носитель (ТН)**.
4. В цикле сканировать **товары**: штрихкод → количество → партия/срок (если включены).
5. Завершить паллету. При включённой настройке — кнопка **«К размещению»** для перехода к размещению.

### Размещение на ТСД

- **По задачам** — список ТН, ожидающих размещения.
- **Свободный скан** — если у роли есть право «ТСД: свободный скан»; можно начать с произвольного ТН.
- Система **предлагает ячейку** по правилам размещения.
- Оператор подтверждает или (если разрешено администратором) указывает другую ячку вручную.

### Отбор на ТСД

1. Выбрать заказ на отгрузку.
2. Сканировать товар / ячейку / количество по подсказкам системы.
3. Завершить отбор по строкам заказа.

### Перемещение на ТСД

- Сканирование товара или ТН.
- Исходная ячейка → целевая ячейка.
- Фиксируется операция «Перемещение» и движение остатков.

## 10. Типовые сценарии

### Сценарий: приёмка поставки

| Шаг | Где | Действие |
|-----|-----|----------|
| 1 | Веб, Приёмка | Создать документ, заполнить план, статус «К исполнению» |
| 2 | ТСД, Приёмка | Принять товар по факту, привязать к ТН |
| 3 | ТСД, Размещение | Разместить ТН в ячейки хранения |
| 4 | Веб, Приёмка | Проверить факт, перевести в «Размещён» |

### Сценарий: отгрузка клиенту

| Шаг | Где | Действие |
|-----|-----|----------|
| 1 | Веб, Отгрузка | Создать заказ, статус «К исполнению» |
| 2 | ТСД, Отбор | Собрать товар по заказу |
| 3 | Веб, Отгрузка | Провести документ («Проведён») |

### Сценарий: контроль остатков

| Шаг | Где | Действие |
|-----|-----|----------|
| 1 | Веб, Остатки | Детальный отчёт с фильтрами |
| 2 | Веб, Остатки | Экспорт в Excel для сверки |
| 3 | — | Расхождения решаются с руководителем / администратором |

### Сценарий: новый товар на складе

| Шаг | Где | Действие |
|-----|-----|----------|
| 1 | НСИ → Номенклатура | Создать карточку товара |
| 2 | НСИ → Упаковки / Штрихкоды | При необходимости — упаковки и ШК |
| 3 | — | Товар доступен в приёмке и отгрузке |

## 11. Статусы — краткая шпаргалка

| Статус | Где используется |
|--------|------------------|
| Новый | Документ создан, работа не начата |
| К исполнению | Передан на выполнение на складе |
| Принят | Товар принят (приёмка, ТН) |
| Размещён | ТН в ячейке хранения |
| Проведён | Отгрузка или операция завершена |
| Свободен | ТН создан, ещё не используется |
| Отменён | Документ отменён |

Названия и цвета статусов администратор может изменить в разделе «Статусы».

## 12. Частые вопросы

**Почему не вижу раздел в меню?**  
Три причины: модуль выключен в настройках; у роли нет права; раздел скрыт администратором в меню.

**Почему после смены прав всё ещё «запрещено»?**  
Права обновляются при следующем переходе по сайту. Обновите страницу или перейдите в другой раздел.

**Чем «Операции» отличаются от «Движений» на обзоре?**  
Операции — **задачи** (что нужно сделать). Движения — **факт** изменения остатков (что уже произошло).

**Можно ли работать без ТСД?**  
Частично: документы приёмки и отгрузки создаются в вебе, но фактическая приёмка и отбор на практике выполняются через ТСД.

**Куда обращаться за новым пользователем или правами?**  
К администратору WMS: разделы «Пользователи» и «Роли».
