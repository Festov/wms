## Быстрый старт

1. **Вход** — откройте адрес системы, введите логин и пароль. У каждого пользователя одна роль; от неё зависит, какие разделы видны.
2. **Обзор** — главная страница показывает активные заказы по потокам и последние движения товара.
3. **ТСД** — пункт «ТСД» в меню открывается в новой вкладке; удобно на терминале сбора данных или планшете на складе.
4. **Нет доступа?** — обратитесь к администратору: возможно, модуль выключен в настройках или роли не хватает права на раздел.

## Термины

| Термин | Значение |
|--------|----------|
| **НСИ** | Нормативно-справочная информация: товары, ячейки, контрагенты и др. |
| **ТН** | Товарный носитель (паллета, контейнер) — единица, на которую кладётся товар при приёмке |
| **ТСД** | Терминал сбора данных — мобильный интерфейс для сканирования на складе |
| **EAV** | Способ хранения пользовательских справочников и документов с произвольными полями |
